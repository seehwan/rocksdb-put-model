Overview

The V5.4 Comprehensive S_max Model addresses the critical need for reliable capacity planning in RocksDB production environments. Unlike statistical percentile-based approaches, this model provides physically-grounded predictions based on:

✅ Device Capacity

Measured bandwidth characteristics from Phase-A experiments

✅ Volatility (CV)

Coefficient of variation to account for system stability

✅ Amplification Factors (WA/RA)

Write and read amplification from experimental data

✅ Compaction Behavior

Intensity, frequency, and chain compaction risk

✅ Thread Concurrency

Background thread contention effects

Key Innovation: The V5.4 model integrates all critical factors affecting RocksDB performance into a single modular architecture, providing production-ready recommendations with appropriate safety margins.

Model Architecture

The V5.4 model uses a modular architecture with five key components:

$$S_{\max} = \frac{C_{\text{device}} \times S_{\text{cv}} \times C_{\text{ctx}} \times C_{\text{thr}}}{O_{\text{comp}}}$$
Component Description Source
C_device Device capacity (QPS) Measured bandwidth / record size
S_cv CV-based safety factor Volatility + chain compaction risk
C_ctx Context-aware correction Phase calibration + context bonuses
C_thr Thread contention factor Background thread count
O_comp Compaction overhead WA × RA × intensity

Component Models

1. Device Capacity Model

$$C_{\text{device}} = \frac{B_w}{\text{record\_size\_mib}}$$

Where B_w is device write bandwidth (1484 MiB/s from Phase-A).

2. CV-Based Safety Factor

Accounts for volatility and chain compaction risk:

  • High risk: 0.2 base factor
  • Moderate risk: 0.3 base factor
  • Low risk: 0.4 base factor

Adjusted by CV: >0.7 = 0.8×, >0.5 = 0.9×, otherwise 1.0×

3. Context-Aware Correction

Phase-specific calibration factors:

Background Threads Contention Factor

5. Compaction Overhead Factor

$$O_{\text{comp}} = (1 + 0.8 \times (\text{WA} - 1)) \times (1 + \text{RA}/10) \times f_{\text{intensity}}$$

Where f_intensity is 1.5 for high, 1.2 for moderate, 1.0 for low intensity.
