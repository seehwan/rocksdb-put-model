Rate Control for Initial Phase Stability

Problem Statement

The initial phase of RocksDB operation exhibits high volatility (CV = 0.538), leading to:

  • Performance overshooting
  • Prediction challenges
  • Inconsistent throughput
  • Lower accuracy (75.0%)

Rate Control Strategy

Rate Control Equation

Rcontrolled = Rpredicted × (1 - α)

where α is the reduction factor (recommended: 5-10%).

Implementation

RocksDB Configuration

# Rate control implementation
import rocksdb

# Predict base throughput
base_prediction = model.predict_s_max(device_bw, 'initial', context)

# Apply 8% rate control
rate_reduction = 0.08
controlled_rate = base_prediction * (1 - rate_reduction)

# Configure RocksDB
options = rocksdb.Options()
options.rate_limiter = rocksdb.RateLimiter(
    bytes_per_sec=int(controlled_rate * 1024 * 1024)
)

WA/RA Sensitivity Key Findings

  • WA Impact: Higher WA reduces utilization due to write overhead (penalty: 85-100%)
  • RA Impact: Higher RA reduces utilization due to read overhead (penalty: 85-100%)
  • Initial Phase: Sensitive to both WA and RA with moderate penalties
  • Middle Phase: Most sensitive to RA changes (compaction-heavy period)
  • Final Phase: Sensitive to WA increases (write accumulation)
  • Combined Effect: Non-linear interaction between WA and RA
  • Utilization Adjustment: ±5-15% based on WA/RA variations
